System Architecture — Modules
🌲
Isolation Forest
200-tree ensemble with 1% contamination. Detects anomalous FX spikes, flash crashes, and irregular volatility via short average path lengths.
🧠
Stacked LSTM
128→64 unit architecture with dropout. 60-day lookback window captures long-term temporal dependencies for rate prediction.
📝
FinBERT NLP
Open-source BERT model fine-tuned on 10K+ financial articles. Processes FOMC/ECB text into sentiment scores [-1, +1].
⚡
Ensemble Combiner
Weighted α-combination: 70% LSTM quantitative + 30% FinBERT qualitative. Captures regime shifts missed by numerical models.
🌐
Flask REST API
5 endpoints: /health, /anomaly, /predict, /sentiment, /retrain. Production-ready with CORS, validation, and JSON responses.
🐳
Docker Pipeline
python:3.9-slim container with Gunicorn WSGI. Portable microservice for Kubernetes, Cloud Run, or AWS Fargate deployment.
